# Sistema de Eventos de Porto Alegre

Sistema de cadastro e notificação de eventos que ocorrem em Porto Alegre,
desenvolvido em Java, orientado a objetos, em modo console.

## Objetivo

Permitir que o usuário se cadastre, consulte eventos, confirme e cancele
participação, com os dados salvos em arquivo.

## Funcionalidades

- Cadastro de usuário
- Cadastro de eventos (nome, endereço, categoria, horário e descrição)
- Consulta de eventos e confirmação de participação
- Cancelamento de participação
- Ordenação por horário, com indicação de eventos em andamento e já ocorridos
- Salvamento e carregamento dos dados no arquivo events.data
